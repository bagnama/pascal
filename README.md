# pascal

This repository is a collection of applications I wrote some time ago (2015-16) while I was studying pascal.

## 2power
This application takes in input a natural number $n$ and returns $2^n$.

## power
This application takes in input the base $b$, the exponent $e$ and returns $b^e$.

## basetodec
It asks you to insert the base and the digits of the initial number (one by one) and returns the same number in deciamal basis.
